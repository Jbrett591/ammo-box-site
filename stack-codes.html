Stack Compatibility

Organized by design.

Because organization shouldn't be an afterthought.

ForgeBox sizes are grouped by Stack Code so compatible boxes share the same footprint. Match the code while building your order to create a cleaner, more organized storage system.

How Stack Codes Work

Some ForgeBox sizes share the same footprint. Those sizes are grouped together under a Stack Code. If two boxes share the same Stack Code, they're designed to stack together. That's it.

Same Code Boxes with the same Stack Code are designed to stack cleanly with one another.
Different Code Boxes with different Stack Codes may not align or stack as cleanly.
While Ordering Look for the Stack Code listed with each box size in the builder.

Look for the Stack Code

When choosing your box size in the ForgeBox builder, the Stack Code will be shown beside the size option. Match codes when you want different boxes to stack together.
